# LEAPRS Project Guidance

Read only the documents and sections relevant to the task, before making changes:

- [REQUIREMENTS.md](../../../REQUIREMENTS.md): roles, permissions, business rules, workflows, and expected behavior.
- [DESIGN_SYSTEM.md](../../../DESIGN_SYSTEM.md): UI layout, wording, components, interactions, and visual consistency.
- [ARCHITECTURE.md](../../../ARCHITECTURE.md): data model, integrations, queues, authentication, implementation details, and known limitations.

Use multiple documents when a task crosses these areas. These root documents are the source of truth; do not duplicate their content in this skill.

Verify current behavior against the relevant code. Distinguish intended requirements from documented implementation differences, and update affected documentation when a change alters it.
